# Synchro — website

The Next.js front end for Synchro. See the [main README](../../README.md) for how to run the whole project.

- `src/app` — pages and global styles
- `src/components` — screens and UI pieces (join form, lobby, game view, results)
- `src/hooks` — `useSocket` (game server connection) and `useWebRTCAudio` (voice chat)
- `src/lib` — small shared helpers
