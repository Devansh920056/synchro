# Synchro

A fast-paced asymmetric multiplayer puzzle game focused on communication, deduction, and real-time collaboration.

## Features

- Room-based multiplayer
- Real-time synchronization
- Unique player perspectives
- Puzzle-solving gameplay
- Match history

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Socket.IO
- PostgreSQL
- Prisma
